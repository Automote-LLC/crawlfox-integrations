# Changelog

## 0.1.1

- JavaScript SDK published as unscoped `crawlfox` (`npm install crawlfox`).

## 0.1.0

- First public SDKs for scrape, batch, search, and logs against `https://api.crawlfox.io`.
- JavaScript, Python, Go, and Rust clients with retries on retryable errors.
- PHP, Java, .NET, Ruby, and Elixir clients with the same HTTP contract.
