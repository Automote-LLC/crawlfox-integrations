# Changelog

## 0.1.0

- First public SDKs for scrape, batch, search, and logs against `https://api.crawlfox.io`.
- JavaScript, Python, Go, and Rust clients with retries on retryable errors only.
- Thin PHP, Java, .NET, Ruby, and Elixir clients with the same HTTP contract.
- No `/v1/crawl` or `/v1/map` — those endpoints do not exist on CrawlFox today.
